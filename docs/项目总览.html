双端差异

主题小程序Web / PWA
数据存放微信本地 Storage浏览器 localStorage
数据互通⚠️ 两端不互通，需各自录入或用「备份 JSON」搬运

改版生效需重新发布试用小程序浏览器刷新（必要时 Ctrl+F5）

使用与部署

Web / PWA
  • 双击 index.html 即用，数据保存在该浏览器
  • 安装成 App：侧边栏「安装到手机（App）」
  • 改版后 Ctrl+F5 强刷；侧边栏底部显示 Web v1.6.0 即最新
微信小程序
  • 开发者工具打开 miniprogram/ → 上传 → 设为体验版
  • 重新扫码后，抽屉底部显示 v1.5.0 即已更新
  • 本机无开发者工具，UI 需在真机确认

开发踩坑备忘

  • 测试注入数据后不要 reload：beforeunload 会落盘覆盖注入，请直接操作内存 DB。
  • <image> 必须自闭合：写成成对标签会被校验判为不配平。
  • 有 bindinput 的 input 必须配 bindblur：静态校验约定。
  • 新页面进侧边导航：需同时登记 nav.js 与 app.json，并遵循页面约定（side-nav / onNav / refresh / pageStyle / 无 px）。
  • 只读聚合页与二级设置页：加入 READONLY_PAGES / SETTINGS_PAGES 豁免检查项。
  • 用户看到旧界面时：先让他确认版本号（小程序抽屉底部 / Web 侧边栏底部）再排查。
