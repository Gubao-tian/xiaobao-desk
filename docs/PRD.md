## 1. 背景与目标

### 1.1 问题陈述

个人日常管理的数据散落在多处：计划在便签、花销在记账 App、读书进度靠记忆、备考与课程进度靠手算、运动打卡靠自觉。由此产生三个具体问题：

1. **记录入口分散** —— 想记一件事情要先想「该打开哪个 App」，成本高到干脆不记。
2. **缺少反馈闭环** —— 记完之后没有可视化回馈，难以形成习惯（"记了又怎样"）。
3. **回顾成本高** —— 想知道"上周做了什么"需要翻多个地方，几乎不可能坚持周复盘。

### 1.2 产品目标

| 编号 | 目标 | 衡量方式 |
| --- | --- | --- |
| G1 | 一个入口完成全天 15 类记录 | 15 个模块可用，单模块完成一次记录 ≤ 3 次点击 |
| G2 | 降低记录成本 | 提供模板库、快速添加、表单默认值、快捷按钮 |
| G3 | 建立正反馈闭环 | 打卡连续天数、日历热力图、自动成长报告、战绩卡片 |
| G4 | 让回顾变得简单 | 日历时间轴（任意一天全记录）、全局搜索、周复盘自动汇总 |
| G5 | 数据自主可控 | 本地优先存储，可一键导出/恢复备份 |

### 1.3 非目标（本期不做）

- 多人协作 / 团队看板
- 强社交功能（排行榜、好友 PK）
- 需要服务端持续运行的实时推送（当前为本地提醒 + 订阅消息可选）
- 跨端自动同步（当前为本地存储 + 手动备份搬运）

## 2. 用户与场景

### 2.1 目标用户

注重自我管理的个人用户，**手机为主要使用端**，偏好轻量、可爱、无学习成本的界面；对数据隐私敏感（不希望数据被强制上传）。

### 2.2 典型场景

| 场景 | 用户行为 | 产品支撑 |
| --- | --- | --- |
| 早上到公司 | 看今天要做什么、打个卡 | 桌面页：问候卡 + 今日日程 + 打卡按钮 |
| 读了一会儿书 | 记本次读了多少页 | 阅读 → 书架 → 输入本次页数 → 累加 |
| 临时记一件事 | 快速塞进便签 | 顶栏「+ 快速添加」或模板库 |
| 周末回顾 | 看这周做了什么 | 周复盘 → 自动生成成长报告 → 写进"做得好" |
| 想知道某天干了啥 | 查看历史 | 桌面日历点那一天 → 当天全部记录 |
| 换手机 / 怕丢数据 | 导出备份 | 我的 → 数据备份 → 导出 / 导入 JSON |

## 4. 功能需求

> 优先级：P0 = 核心必须有；P1 = 体验提升；P2 = 锦上添花。
> 每条含「描述 / 规则 / 验收标准」。

### 4.1 通用能力

| ID | 优先级 | 需求 | 规则与验收 |
| --- | --- | --- | --- |
| FR-001 | P0 | **统一数据模型** | 所有模块数据落在单一 DB 结构；缺失字段自动用默认值补齐，老数据升级不丢失 |
| FR-002 | P0 | **全模块增删改** | 每个模块支持新增、编辑（✎）、删除（🗑）；编辑不得产生重复条目 |
| FR-003 | P0 | **表单可靠提交** | 小程序侧一律使用 `<form bindsubmit>`，规避真机 input/blur/tap 时序导致的丢值 |
| FR-004 | P0 | **弹层交互** | 小程序弹层为不透明全屏 sheet；点遮罩背景才关闭（`target === currentTarget`），点输入框绝不关闭 |
| FR-005 | P0 | **空状态** | 每个列表必须有友好空状态文案与表情 |
| FR-006 | P0 | **操作反馈** | 保存/删除后必须有 toast 提示；达成里程碑（读完一本书、任务全完成）有彩带 |
| FR-007 | P1 | **数据备份** | Web 导出/导入整库 JSON；小程序复制 JSON 并生成文件分享 |
| FR-008 | P1 | **全局搜索** | 跨 12 类数据检索，结果点击可跳转到所属模块；Web 支持 Ctrl/Cmd+K |
| FR-009 | P1 | **提醒通知** | 计划/锻炼按时间点、喝水按间隔；小程序本地弹窗，Web 浏览器通知 |
| FR-010 | P2 | **模板库** | 提供计划/复盘/便签三类模板一键套用 |
| FR-011 | P2 | **AI 助理** | 小程序接云端大模型（流式输出、带用户数据上下文）；Web 降级为本地规则建议 |
| FR-012 | P2 | **战绩卡片** | Canvas 绘制数据卡片，小程序存相册，Web 下载 PNG |
| FR-013 | P1 | **渲染健壮性** | 任一模块渲染异常时显示兜底提示卡（含错误与版本号），禁止静默空白 |
| FR-014 | P1 | **版本可见** | 小程序抽屉底部、Web 侧边栏底部显示版本号，便于确认所跑构建 |

## 5. 非功能需求

| 类别 | 要求 |
| --- | --- |
| 性能 | Web 单文件无构建依赖，首屏秒开；小程序页面切换无白屏；列表渲染无卡顿 |
| 兼容 | Web：现代 Chrome / Safari / Edge，支持 PWA 安装与离线；小程序：微信主流版本，iOS 与 Android |
| 视觉 | 移动端优先；小程序使用 rpx（WXML/WXSS 禁用 px）；支持日/夜模式与自定义背景 |
| 数据 | 本地优先（Web `gubao_desk_v1` / 小程序 Storage）；加载时补齐缺失字段；离线可用 |
| 隐私 | 默认不上传任何数据；云端同步需用户主动登录触发 |
| 健壮性 | 渲染异常有兜底；旧缓存能被识别（版本号 + Service Worker 版本号） |
| 可维护性 | 双端共享同一套领域逻辑命名（如 `searchAll` / `dayLevel` / `tlNodes`），便于同步演进 |

## 6. 交互与视觉规范

1. **导航**：移动端从左上角轻量卡片按钮唤起抽屉；**抽屉打开时该按钮隐藏**，点抽屉外空白关闭。
2. **列表项**：左侧图标/标题 + 右侧操作（✎ 编辑、🗑 删除）；删除需二次确认。
3. **弹层**：小程序为不透明全屏 sheet（避免"透过遮罩看到上一层"的错觉）；Web 为半透明模糊遮罩。弹层内按钮不重复（如只读弹窗只保留「关闭」）。
4. **表单**：小程序统一 `<form bindsubmit>`；枚举型选择用内联按钮组而非 picker；日期仍用原生 picker。
5. **反馈**：保存 → toast；达成 → 彩带；错误 → 明确文案，不允许静默失败。
6. **文案**：轻松可爱、口语化（例："书架空空的，添加第一本书吧"）。

## 7. 数据模型（摘要）

单一 DB；Web 存储键 `gubao_desk_v1`，小程序同结构。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `profile` | object | 昵称 / 签名 / 头像 / 标签 |
| `checkins` | map | 日期 → `{at}` |
| `plans` | map | 日期 → `[{id,name,done,prio}]` |
| `courses` / `exam` | array | 课程 / 备考科目 |
| `studyLog` / `readLog` | map | 日期 → 分钟 |
| `workout` | map | 日期 → `[{id,type,min,burn}]` |
| `finance` | array | `{type,amount,cat,note,date}` |
| `goals` | array | 储蓄目标 `{name,target,saved}` |
| `ideas` / `pubs` | array | 自媒体灵感 / 发布 |
| `books` / `quotes` | array | 书架 / 摘抄 |
| `skills` / `skillLog` | array | 技能 / 练习记录 |
| `memos` | array | 便签（内容可被搜索） |
| `reviews` | map | 周起始日 → `{good,bad,next,at}` |
| `reminders` | object | `plan/workout`（时间点）、`water`（间隔） |

## 8. 技术架构与约束

```
┌─────────────── UI 层 ───────────────┐
│ 小程序页面(WXML/WXSS) │ Web 单页(index.html) │
├─────────────── 逻辑层 ──────────────┤
│ utils/store · search · report · remind · theme · nav │
│ index.html 内同名函数（searchAll / tlNodes / dayLevel …） │
├─────────────── 数据层 ──────────────┤
│ 本地存储（localStorage / Storage） ←→ 云端同步（可选） │
└─────────────────────────────────────┘
```

**关键约束与已定方案**

| 约束 | 方案 |
| --- | --- |
| 真机 setData 异步 + blur/tap 时序不确定 | 弹层全面采用 `<form bindsubmit>` |
| 点输入框弹层消失（tap 冒泡） | 遮罩用 `e.target === e.currentTarget` 判断 |
| 半透明遮罩被感知为"界面重叠" | 小程序弹层遮罩改为完全不透明 |
| 旧缓存让用户看到过期界面 | 版本号可见 + Service Worker 版本号升级 |
| 小程序无法打开外部浏览器 | 「联网搜书」改为复制关键词到剪贴板 |
| 枚举 picker 在部分环境不可交互 | 改为内联可选按钮组（分类/优先级/状态/平台） |
